# gestion-reservas-software-fj
Sistema integral orientado a objetos para la gestión de clientes, servicios y reservas para la empresa Software FJ. Desarrollado en Python para el curso de Programación (código 213023) de la UNAD. Implementa abstracción, encapsulación, herencia, polimorfismo, excepciones personalizadas y registro de eventos en archivo de logs.
